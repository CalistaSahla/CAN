# CAN: Can You Trust This?

**Explainable Web Trust Intelligence Platform**  
*Switchfest 2026 Competition Entry — Web Development Category*

## 💡 Concept & Vision

**CAN** ("Can You Trust This?") is an explainable web trust intelligence platform designed to bridge the gap between technical web signals and everyday human decision-making. 

Instead of presenting an arbitrary binary label ("Safe" / "Dangerous") or a black-box safety score, CAN decomposes web trust into observable, verifiable technical evidence across **6 Trust DNA Dimensions**:

1. **Security** — HTTPS/TLS configuration, HSTS, security header enforcement.
2. **Authenticity** — Domain registration age, SSL certificate issuer, identity matching.
3. **Transparency** — Privacy policy visibility, contact information clarity, operator ownership.
4. **Behavior** — Form inputs, tracking scripts, data collection categories.
5. **Network** — Third-party host dependencies, CDNs, analytics providers, payment gateways.
6. **Data Exposure** — PII collection footprint, form security, data transmission risks.

Every finding generated by CAN follows the **CAN Explain Standard**:
- **What**: What was observed?
- **Why**: Why does this matter?
- **Evidence**: What technical data backs this up?
- **Impact**: How does this affect the user?
- **Action**: What practical steps should the user take?

| Route | Description | Mode |
|---|---|---|
| `/` | **Landing Page** — Editorial introduction, Trust DNA 6 dimensions, Explainability highlights, and instant URL scan trigger | Production |
| `/scan` | **Dynamic Scan Engine** — Animated multi-stage evidence collection simulation with real-time step progress | Production |

## 🛠️ Technology Stack

- **Frontend**: Next.js 16 (App Router), React 19, Vanilla CSS & Design Tokens, Tailwind CSS
- **Backend Engine**: FastAPI (Python 3.11), SQLAlchemy, Pydantic, HTTPX, SQLite/MySQL
- **Security Controls**: SSRF URL validation, private IP filter, in-memory rate limiting
- **Testing**: `pytest` (Backend), `ESLint` & `Next.js Build` (Frontend)

## 💻 Local Setup & Running

### 1. Frontend (Next.js)

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.

```bash
# Run production build check
npm run build

# Run linting check
npm run lint
```

### 2. Backend (FastAPI Python Service)

```powershell
# Setup virtual environment
python -m venv backend/.venv
backend/.venv/Scripts/python -m pip install -r backend/requirements.txt
backend/.venv/Scripts/python -m pip install pytest

# Run backend API server
& "backend/.venv/Scripts/python.exe" -m uvicorn app.main:app --app-dir backend --reload --port 8000
```
API Documentation available at **http://localhost:8000/docs** or health check at **http://localhost:8000/health**.

### 3. Running Backend Test Suite

```powershell
$env:PYTHONPATH="backend"
& "backend/.venv/Scripts/pytest.exe" backend/tests
```

All 20 unit tests verify rate limiting, URL safety, evidence collection, scoring, and API routes.
